# Design Pattern Facade

## Descrição

Projeto desenvolvido em Java com aplicação do padrão de projeto Facade, demonstra como simplificar a interação com sistemas complexos através de uma interface unificada.

## Tecnologias

- Java
- Design Patterns

## Conceitos Aplicados

- Padrão Facade
- Encapsulamento
- Organização de camadas

## Objetivo do Projeto

Compreender e aplicar o padrão Facade em um contexto prático.
